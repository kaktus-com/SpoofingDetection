detect2 / IMU-displacement detector

Windowed likelihood comparison

Raw carrier phase is fitted with per-signal quadratic nuisance terms and a motion model. The benign hypothesis fits one common proper frame rotation; the spoofed hypothesis fits one shared unit transmitter direction. Gamma = J_spoofed − J_benign. Positive favors benign, negative favors spoofing, subject to quality checks.

Movement is estimated from IMU specific force and supplied attitude, with zero initial velocity in each window. No truth displacement or velocity is used before predictions are saved. Any injected input errors are recorded in run settings. These synthetic results do not establish real-sensor performance, attitude estimation or full navigation. Full-rank 3D motion is required by this first implementation; stationary, polynomial-only and planar/coning controls can be inconclusive. This is a conservative implementation policy, not a claim that all planar motion is inherently undetectable.

64 windows; 23 conclusive labeled windows; 23 correct; 41 inconclusive; 0 false alarms; 0 missed detections.
