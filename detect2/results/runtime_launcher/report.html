Interruptions are explicit

  • A serial disconnect stops this session; there is no silent reconfiguration or stitching across a receiver reset.
  • Required-stream timeouts, receiver epoch/clock discontinuities, backwards PX4 clocks, corruption and queue/disk errors mark failure.
  • Stopping while armed leaves native logging active and marks native collection pending. After disarm, run the printed --finalize command. Collection preserves a newer unrelated native log.
  • A second Ctrl+C during native collection preserves partial data for a later retry.
./start_recording --finalize /absolute/session/path

This is an acquisition launcher. External GNSS↔PX4 timing and field spoofing detection remain unvalidated. Active TIMESYNC is not enabled here. Native file presence and capture integrity do not establish measurement-clock alignment.
