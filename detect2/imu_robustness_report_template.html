Own IMU integration: controlled-error tests

Specific force is rotated with supplied attitude, gravity is removed, and acceleration is integrated in short windows with zero initial velocity. The rotating antenna offset is included. PX4 displacement is deferred.

The same carrier data, epochs and detector thresholds are used for every error level. Both carrier cases share one IMU realization. White accelerometer noise, constant body-frame bias, a body-fixed supplied-attitude error and a signed IMU clock offset are varied separately, followed by one combined-error case. Inputs and seed are saved beside each run.

These levels are engineering stress settings, not a calibrated sensor model. One noise seed and these synthetic motions cannot establish detection probabilities or real-flight accuracy. Attitude remains supplied; gyro-based attitude estimation has not been added.

Displacement, phase, decisions and gamma

Polynomial-removed motion is evaluated separately from raw integration drift. Gamma differences use the same carrier windows rerun with held-out oracle displacement; no oracle result initializes or corrects the IMU estimates.
