Motion, frames and antenna geometry

Analytic movement with explicit coordinate conversions. Inspect the body and antenna separately, rotate the view and scrub through time. This report contains geometric truth, not a spoofing detector or measured receiver signals.

Site: __SITE__. Height is above the WGS-84 ellipsoid, not mean sea level.

Dashed: IMU/body path · Purple: antenna path · rod: rigid antenna offset.
World axes: E/N/U. Body axes: F/R/D. Paths use equal distance scales; view is orthographic. Drag to rotate.

Antenna pointing is its upward axis (−body Down), rigidly attached to the body. In the cone view, purple is this unit direction and orange is Body Forward; vector origins are deliberately shared.

NED roll/pitch/yaw describes the drone's FRD body. Zero yaw faces North; +90° faces East. The exported quaternion rotates body vectors to ENU, so zero Euler angles does not give the identity quaternion. Ideal accelerometer values include gravity; a level stationary FRD sensor reads approximately [0, 0, −9.80665] m/s².
